# 白色小狗桌面宠物设计

## 目标

制作一个本地运行的 Linux Electron 桌面宠物。它以透明、无边框、始终置顶的小窗口显示一只参考用户照片创作的卡通白色卷毛小狗，既可安静陪伴，也会随机活泼捣蛋。

## 用户体验

- 启动后，约 180px 高的小狗出现在屏幕右下角；用户可将其拖到任意位置。
- 小狗定时在两类状态之间随机切换：
  - 陪伴：坐着眨眼、摇尾巴、趴下打盹、朝鼠标方向观察。
  - 捣蛋：沿屏幕底边散步、跳跃、叼粉色编织玩具跑过、探头。
- 单击触发即时亲近反应；连续点击触发转圈或打滚。
- 右键菜单提供暂停/继续、声音开关、重置位置、退出。
- 随机行为设置冷却，避免高频动画影响工作；不会读取屏幕内容、联网或干扰键盘输入。

## 视觉素材

素材基于用户提供照片的可识别特征重新创作，使用透明背景：白色蓬松卷毛、圆黑眼鼻、短腿。玩耍状态会搭配粉色编织玩具。素材用于应用内动画，不直接使用室内照片背景。

## 架构

- Electron 主进程：创建透明、无边框、置顶窗口；配置窗口位置；提供系统右键菜单；处理退出。
- 渲染进程：显示宠物、监听拖拽与点击、管理宠物行为状态，以及播放 CSS 动画。
- 预加载桥接：仅暴露菜单和窗口控制所需的最小接口。
- 静态资源：本地宠物插画及可选音效；不依赖外部服务。

## 交互与状态

渲染层维护 `idle`、`sleep`、`look`、`walk`、`jump`、`toy`、`happy`、`roll` 等互斥状态。状态机在当前动画结束并经过冷却时间后选择下一动作；点击优先打断可中断的随机动作。拖拽中禁用点击判定，避免移动窗口时误触互动。

## 错误处理

- 若可选音效无法播放，保持静音并继续动画。
- 若窗口位置超出当前显示器可视区域，启动时重置到主显示器右下角。
- 菜单及窗口控制失败时不影响宠物动画；在开发日志中记录错误。

## 验收与验证

1. 本机启动后窗口透明、无边框、始终置顶，且可拖动。
2. 单击和连续点击有对应动画反馈。
3. 可观察到陪伴和捣蛋两类随机行为，且不会持续高频跳动。
4. 右键菜单可暂停、恢复、重置位置和退出。
5. 断网状态下可正常运行。
